# Canvas de Definição do Problema

**Projeto:** Sistema de Apoio ao 1º Hackathon do Curso

**Disciplina:** Engenharia de Software I — Profa. Lauriana Paludo — IFPR Campus Pinhais

**Equipe:** Miguel Gerhardt Soares e Silva, Michelly Morena de Castro Loyola

**Etapa:** Sprint 0 — Semana 2

---

### Quem é o stakeholder principal? Qual seu papel no Hackathon?

A comissão organizadora. Planejar e executar o evento.

### Qual é o problema hoje? Como o processo é feito atualmente, sem o sistema?

Não há um sistema eficiente que reúna todas as necessidades do projeto em um lugar só. Atualmente tudo é feito de maneira arcaica via planilhas e e-mail.

### Por que isso é um problema? Que impactos e consequências ele gera?

É trabalhoso gerenciar os dados manualmente, isso pode gerar perdas, duplicações desnecessárias e lentidão.

### Para quem mais isso é um problema, além do stakeholder principal? (participantes, jurados, público)

Para todos os envolvidos. As equipes participantes não têm visão clara do cronograma e status. Os jurados não têm padrão para lançar as notas. A coordenação é prejudicada pelos dados não serem centralizados, o que atrapalha na geração de relatórios e estatísticas. E, por fim, não há clareza das informações e cronogramas para a comunidade externa.

### Qual seria o cenário ideal depois que o sistema existir?

Um sistema centralizado onde a comissão possa gerenciar as inscrições, o cronograma e os resultados. As equipes possam acompanhar resultados e enviar as submissões. Os jurados possam avaliar mais adequadamente.


### Que perguntas ainda estão em aberto e precisam ser validadas com a comissão?

- O login deverá ser vinculado ao e-mail institucional?
- Quais e quantas são as categorias de avaliação que os jurados usarão?
- Deve-se usar conceitos (A, B, C ou D) ou notas?
- Há necessidade de uma seção para os feedbacks dos jurados (em texto)?
- É preferível um login por equipe ou logins individuais para cada membro?
- Qual formato de submissão o sistema deve aceitar (ex: link de repositório, upload de arquivo)?
