## Canvas

| Pergunta-guia | Resposta da equipe |
|---|---|
| **Qual framework (ou combinação) a equipe escolhe: Scrum, Kanban, XP, ou um híbrido?** | Híbrido de Scrum + Kanban. |
| **Por quê?** | A equipe é uma dupla  e o projeto tem um prazo fixo (Semana 19) com marcos previsíveis (elicitação de requisitos na Semana 6, backlog na Semana 8, etc). O timebox do Scrum garante que os marcos da disciplina sejam batidos, enquanto o fluxo contínuo do Kanban evita a sobrecarga de comprometer a semana inteira com uma lista fechada de tarefas — mais realista para o ritmo de uma dupla. |
| **Quais cerimônias/rituais a equipe vai adotar?** | Sprints semanais. Um único encontro semanal (30–40 min) que combina Planning + Review + Retrospectiva. Sem daily formal — check-in assíncrono via mensagem sempre que o quadro é atualizado. Sem papéis formais de Scrum Master ou Product Owner. |
| **Qual ferramenta será usada para o quadro de tarefas?** | GitHub Projects — já é o repositório do projeto, sem custo adicional, e tem quadro Kanban nativo. Colunas: A Fazer → Fazendo → Em Revisão → Pronto, com limite de WIP = 1 tarefa "Fazendo" por pessoa. |
| **Como será a cadência de entregas da equipe até a Semana 19?** | Ciclos semanais entregando incrementos utilizáveis, alinhados aos marcos da disciplina: Semana 6 (requisitos elicitados), Semana 8 (backlog do projeto), sprints seguintes evoluindo cadastro de equipes → agenda do evento → painel de avaliação de jurados, até o sistema testado e funcional na Semana 19. |
