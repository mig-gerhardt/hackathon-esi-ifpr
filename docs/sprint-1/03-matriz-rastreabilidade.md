# Matriz de rastreabilidade

| RF (user story) | Caso de uso | Tela |
|---|---|---|
| **RF01** — Como organizador, quero configurar o evento para definir datas, cronograma e critérios | UC04 — Configurar o evento | Configuração do evento |
| **RF02** — Como organizador, quero atribuir jurados para que eles possam avaliar os projetos | Atribuir jurados | Gestão de jurados |
| **RF03** — Como participante, quero criar uma equipe para me inscrever no hackathon | UC01 — Criar equipe | Cadastro de equipe |
| **RF04** — Como equipe, quero submeter meu projeto para que ele seja avaliado | UC02 — Submeter o projeto | Submissão de projeto |
| **RF05** — Como jurado, quero lançar notas para avaliar os projetos | UC03 — Lançar notas / Avaliar projetos | Avaliação de projetos |
| **RF06** — Como participante ou visitante, quero visualizar o cronograma para saber as datas do evento | Visualizar cronograma | Cronograma |
| **RF07** — Como participante ou visitante, quero acompanhar os resultados para ver o ranking | Acompanhar resultados | Resultados / Ranking |
